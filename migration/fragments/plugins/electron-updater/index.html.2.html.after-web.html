FAQ

Electron Updater plugin FAQ

How do I install the Electron Updater plugin in an Electron app?

Run "bun add @capgo/electron-updater" (or "npm install @capgo/electron-updater"), then follow the Electron setup steps in the guide and the GitHub README.

Does @capgo/electron-updater work with React, Vue and Angular?

Yes. Electron Updater is an Electron package, so it works with any web framework that runs inside Electron, React, Vue, Angular, Svelte and plain JavaScript.

Is @capgo/electron-updater free and open source?

Yes. The source code is public on GitHub at https://github.com/Cap-go/electron-updater/ and the package is free to install from npm. Bug reports and pull requests are welcome.
