FAQ

Capacitor Patch plugin FAQ

How do I install the Capacitor Patch plugin in a Capacitor app?

Run "bun add @capgo/capacitor-patch" (or "npm install @capgo/capacitor-patch"), then run "bunx cap sync" so the iOS and Android projects pick up the native code. Import it from "@capgo/capacitor-patch" in your app code.

Does @capgo/capacitor-patch work with React, Vue and Angular?

Yes. Capacitor Patch is a Capacitor package, so it works with any web framework that runs inside Capacitor, including Ionic, React, Vue, Angular, Svelte and plain JavaScript.

Which Capacitor version does @capgo/capacitor-patch support?

Capgo plugins follow Capacitor's major version: use the plugin major version that matches your Capacitor major version (for example plugin v8 with Capacitor 8). The compatibility table in the GitHub README lists the maintained versions.

Is @capgo/capacitor-patch free and open source?

Yes. The source code is public on GitHub at https://github.com/Cap-go/capacitor-patch/ and the package is free to install from npm. Bug reports and pull requests are welcome.

Can I update code that uses Capacitor Patch without an App Store review?

Installing or upgrading the plugin changes native code, so it needs a new store build. After that, JavaScript, HTML and CSS changes that call the plugin can ship instantly with Capgo live updates.
