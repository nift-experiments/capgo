FAQ

App Tracking Transparency plugin FAQ

How do I install the App Tracking Transparency plugin in a Capacitor app?

Run "bun add @capgo/capacitor-app-tracking-transparency" (or "npm install @capgo/capacitor-app-tracking-transparency"), then run "bunx cap sync" so the iOS and Android projects pick up the native code. Import it from "@capgo/capacitor-app-tracking-transparency" in your app code.

Does @capgo/capacitor-app-tracking-transparency work with React, Vue and Angular?

Yes. App Tracking Transparency is a Capacitor package, so it works with any web framework that runs inside Capacitor, including Ionic, React, Vue, Angular, Svelte and plain JavaScript.

Which Capacitor version does @capgo/capacitor-app-tracking-transparency support?

Capgo plugins follow Capacitor's major version: use the plugin major version that matches your Capacitor major version (for example plugin v8 with Capacitor 8). The compatibility table in the GitHub README lists the maintained versions.

Is @capgo/capacitor-app-tracking-transparency free and open source?

Yes. The source code is public on GitHub at https://github.com/Cap-go/capacitor-app-tracking-transparency/ and the package is free to install from npm. Bug reports and pull requests are welcome.

Can I update code that uses App Tracking Transparency without an App Store review?

Installing or upgrading the plugin changes native code, so it needs a new store build. After that, JavaScript, HTML and CSS changes that call the plugin can ship instantly with Capgo live updates.
